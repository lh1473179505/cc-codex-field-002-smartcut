# fixtures

`source.mp4` is a 5.000 second, 24 fps, 320x240 test clip generated by `scripts/generate_fixtures.sh`.

Properties that matter for cutting:

- Video: H.264 (`libx264`), `yuv420p`, no B-frames, fixed GOP of 12 frames, closed GOP, `sc_threshold=0` so keyframes land on frames 0, 12, 24, 36, … (PTS 0, 0.5, 1.0, 1.5, … seconds).
- Audio 0: AAC, 48 kHz, mono, 440 Hz sine, aligned to video.
- Audio 1: AAC, 48 kHz, mono, 880 Hz sine, delayed by 100 ms relative to video (`adelay=100ms` baked in).
- Subtitles: `mov_text` muxed from `source.srt`. The same cues also live in `source.srt` if you prefer an external file.

Do not regenerate or replace this file unless you also update any documented timestamps that depend on it.
